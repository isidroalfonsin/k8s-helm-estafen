🌐 ACCESSING THE APPLICATION

  The frontend is exposed via a LoadBalancer service.
  
  Get the LoadBalancer IP:
  
    $ kubectl get svc frontend-external -n {{ .Values.namespace.name }}
  
  Once the EXTERNAL-IP is assigned, access the application:
  
    $ curl http://<EXTERNAL-IP>
  
  Or open in your browser: http://<EXTERNAL-IP>

  Note: On kind/minikube, use port-forward instead:
  
    $ kubectl port-forward -n {{ .Values.namespace.name }} svc/frontend-external 8080:80
  
  Then visit: http://localhost:8080

🔍 MONITORING YOUR DEPLOYMENT

  Check all pods status:
    $ kubectl get pods -n {{ .Values.namespace.name }}

  View all services:
    $ kubectl get svc -n {{ .Values.namespace.name }}

  View logs from a specific service (example: frontend):
    $ kubectl logs -n {{ .Values.namespace.name }} -l app=frontend --tail=50 -f

  Check all deployments:
    $ kubectl get deployments -n {{ .Values.namespace.name }}

📊 MICROSERVICES DEPLOYED

  - frontend           - Web UI (Go)
  - cartservice        - Shopping cart (C#)

  - checkoutservice    - Checkout process (Go)
  - recommendationservice - Product recommendations (Python)
  - adservice          - Advertisements (Java)
  - loadgenerator      - Load testing (Python/Locust)
  - redis-cart         - Redis database for cart

🛠️ USEFUL COMMANDS

  View all resources:
    $ kubectl get all -n {{ .Values.namespace.name }}

  Describe a specific pod:
    $ kubectl describe pod -n {{ .Values.namespace.name }} <pod-name>

  Execute shell in a pod:
    $ kubectl exec -it -n {{ .Values.namespace.name }} <pod-name> -- /bin/sh

  Update the deployment:
    $ helm upgrade {{ .Release.Name }} . -n {{ .Values.namespace.name }}

  Rollback to previous version:
    $ helm rollback {{ .Release.Name }} -n {{ .Values.namespace.name }}

  Uninstall:
    $ helm uninstall {{ .Release.Name }} -n {{ .Values.namespace.name }}
